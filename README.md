# 🎉 The Official Sadaf Chronicles™

A hilarious, playful, interactive website made specially for your best friend **SADAF**!

## ✨ Features Included:
- 👑 **Live Sadaf Status Monitor**: Battery percentage (4%), text reply speed (30s or 5 business days), snack cravings, and rotating daily mottos.
- 📱 **iMessage Texting Simulator**: Ask if she's free and get funny, realistic Sadaf responses.
- 🔊 **Voice & Soundboard**: Interactive speech synthesis & Web Audio API sound effects (plays catchphrases like *"I'm literally starving"*, *"spill the tea"*, *"I'm on my way"*).
- 🏃‍♀️ **The Runaway Complaint Form**: A button that literally runs away from the cursor whenever anyone tries to file a complaint against Sadaf!
- 📜 **Official Bestie Contract**: Lifetime warranty, seal-able with confetti.
- 🔮 **Daily Sadaf Horoscope**: Algorithmic predictions of shopping carts and iced matcha lattes.
- 🧠 **Trivia Roast Quiz & Wholesome Popups**: Balances funny roasts with genuine friendship appreciation.

---

## 🚀 How to Open and View
Simply double-click [`index.html`](./index.html) to open it in Chrome, Edge, Safari, or any browser of your choice!

Alternatively, start a local server:
```bash
npx serve .
# or
python -m http.server 8000
```
